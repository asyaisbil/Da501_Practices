1. Advanced Set Printer (20 min): Read inputs from the user until -1 is entered. For an input that is not a number, print Invalid! and skip it; negative numbers other than -1 are also invalid. At the end, print the valid numbers on one line, without duplicates and in reverse order. Then print the number that was entered most often and how many times it was entered; in a tie, the number entered first wins. If there are no valid numbers, print No numbers!.
